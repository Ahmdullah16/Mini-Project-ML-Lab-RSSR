# Seven-architecture budget and tiling preflight

This is executed implementation evidence, not trained-model quality. No dataset, held-out image, checkpoint or optimizer was used. Historical frozen results are unchanged.

## Budget search

[Machine-readable preflight](../reports/architecture-budget-preflight.json) records all 448 candidates: seven configurations × 32 even widths (2–64) × RGB/four-band inputs. The fixed reference is M7 width16, native×2, window4, input batch1 at64×64. The initial search ran in4.90seconds; the final report serializer rerun took3.65seconds on CPU with2threads, with identical choices. Four accounting tests passed3.50seconds, including hand calculations and cleanup after failure.

A parameter is a stored learned scalar, including biases and window positions. One MAC is a multiply-accumulate. A convolution costs N×Hout×Wout×Cout×(Cin/groups)×Kh×Kw MACs. Same-width self-attention with B windows, L tokens and D channels costs B(4LD²+2L²D): projections plus the two attention matrix products. Feed-forward Linear layers are counted separately. Padded window tokens are included. Bias additions, normalization, activations, pooling, softmax, interpolation, elementwise work and memory movement are excluded. These are partial counts, **not full FLOPs, measured runtime or a complete training budget**.

Eligibility uses |candidate−reference|/reference≤5% for parameters and≤10% for partial MACs. For example105parameters versus100is exactly5%. Among eligible candidates choose the smallest maximum normalized deviation, with smaller width breaking ties. With no eligible candidate, record the closest diagnostic candidate and explicitly fail eligibility. This preflight proposes widths; it does not change or execute protocol-v2 training.

M2 has a different ratio of parameters to per-pixel work because its channel gate includes globally pooled layers. Do not widen the tolerance after seeing quality, pretend it is matched, or infer no possible match outside this bounded search. A future comparison must either disclose this mismatch or preregister a revised design before new test access. Equal counts also do not guarantee equal representational capacity or runtime.

## Actual tiled discrepancy

[Seven-row seam report](../reports/architecture-seam-smoke.json) records executed native×2 random-weight checks: input1×3×65×97, output1×3×130×194, width4, tile32, overlap halo32, seed76. The seam strip comprises two output pixels on each side of every internal tile boundary. Values are absolute full-frame-versus-tiled output differences, not errors against HR. Output hashes and means inside/outside strips are retained.

| Model | Maximum absolute difference |
|---|---:|
| M1 | 2.3842e-7 |
| M2 | 4.2558e-5 |
| M3 | 3.5763e-7 |
| M4 | 4.0054e-5 |
| M5 | 2.3842e-7 |
| M6 | 1.1921e-7 |
| M7 | 6.5625e-5 |

The predefined finite/dimension checks passed for all models; models without A additionally passed maximum discrepancy≤1e-6. Global channel pooling in A sees different context in each tile, so there is no claimed universal equality or tolerance for M2/M4/M6/M7. M6's small discrepancy on this fixture does not establish equivalence. T window origins are aligned; replicated padding and convolution halos remain explicit.

These checks do not establish trained-image seam quality, cascade equivalence, maximum-size execution or perceptual acceptability. Those require separate evidence. The existing42-row matrix remains an untrained bounded export test, not a final trained capability matrix.

## Reproduction

With the existing pinned environment and `PYTHONPATH=src`, run only after relevant source changes:

```text
python -m pytest tests/test_model_cost.py -q
python scripts/preflight_architecture_budgets.py
python scripts/check_registry_seams.py
```

Reports include source hashes, environment, seeds, commands and actual durations. No scientific quality numbers are generated by these commands.
