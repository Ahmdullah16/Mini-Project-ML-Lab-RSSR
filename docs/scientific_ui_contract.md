# Scientific UI contract

VERIFIED: presentation does not alter model or lesson mathematics. SiteFact counts derive from registries with named sources and limitations. Configuration is not execution or scientific validation. Existing model/acquisition/evidence records remain authoritative; no duplicate scientific registry introduced.

Passports are created only after a successful output. They bind input bytes, RGB shape/encoding where applicable, checkpoint/output SHA256, scale, measured pipeline time, completion timestamp and software identity. Session-only; explicit export. They exclude source URLs, coordinates and image bytes. Original provenance exports can contain acquisition coordinates; review before sharing.

Imported manifests are bounded and inert: no file fetching, command execution or model execution. Matching input/checkpoint/scale does not establish protocol/hardware/software equivalence. No-reference uploads and display RGB receive no invented HR scores. Bicubic differences remain disagreement. SAM requires meaningful compatible bands. Frozen studies retain scope and uncertainty. High scales retain unverified-detail warnings.

NOT VERIFIED: full cross-sensor calibration/registration, eligible paired study, full advanced viewer, Pareto eligibility engine and complete seven-model passport matrix. Presentation cannot close scientific gates.
